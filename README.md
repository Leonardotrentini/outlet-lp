# outlet-lp

Landing pages estáticas do outlet (grupos e vendedores).

## Arquivos

- `lp-outletgrupos.html` — página para grupos
- `lpoutletvendedores2.html` — página para vendedores

## Testar localmente

Na pasta do projeto:

```bash
python -m http.server 8889
```

Abra no navegador:

- http://127.0.0.1:8889/lp-outletgrupos.html
- http://127.0.0.1:8889/lpoutletvendedores2.html
